# Семейный психолог онлайн · Анна Щеголихина

Статический production-сайт. Главная страница расположена в `index.html`; страницы оферты, политики конфиденциальности, согласия и очного приёма в Калининграде находятся в одноимённых папках.

Портреты и другие production-ресурсы хранятся в `assets/`. Макеты из `previews/` предназначены только для локального выбора дизайна и исключены из Git.
